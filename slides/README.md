# 功率控制与超级电容 · 培训幻灯片

给硬件组新人培训用的单页应用（SPA）式幻灯片。**双击 `index.html` 即可打开，不需要服务器、不需要联网。**

> 重心说明：**功率控制只讲逻辑（13 页），超级电容逐颗讲选型（38 页）**。
> 后半程每颗器件都回答三件事——它干什么、为什么选它（带数字）、换成别的会怎样。

## 四、怎么改内容

内容拆成两个数据文件，加载时合并成一个数组：

```html
<script src="js/slides-p1.js"></script>   <!-- 开场 + Part I -->
<script src="js/slides-p2.js"></script>   <!-- Part II + 结尾 -->
```

每个文件都以 `window.SLIDES = (window.SLIDES || []).concat([...])` 开头，所以**顺序即加载顺序**——想调整部分顺序就调 script 顺序。

单页格式：

```js
{
  id: 'sel-mos',          // 唯一 id，深链接与交互注册都用它
  part: 'Part II',
  partKey: 'p2',          // p0 开场 / p1 功率控制 / p2 超级电容（决定配色）
  title: '半桥 MOS：IRFH7440 与一张损耗账',
  sub: '12.5.4 · 选型就是算损耗',
  html: `...`
}
```

新增一页 = 在数组里加一项。`cls: 'cover'` 是封面，`cls: 'divider'` 是分区页。

### 加交互
在 `js/deck.js` 末尾的 `INIT` 表里按 **slide id** 注册：

```js
INIT['my-slide'] = el => { el.querySelector('.my-btn').onclick = () => { ... }; };
```

> ⚠️ **注册键必须等于 `slides-p*.js` 里的 `id`**。两处不一致时交互会静默失效，
> 页面上只留下初始的 `0.00` 之类占位值——本项目开发时就踩过这个坑。

有动画的页返回 `{ pause, resume }` 即可。

### 改配色
`css/deck.css` 顶部 `:root`：

```css
--p1: #2563eb;     /* Part I 主色 */
--p2: #0d9488;     /* Part II 主色 */
--on: #16a34a;     /* MOS 导通 */
--off: #94a3b8;    /* MOS 关断 */
--pwm: #3b82f6;    /* MOS 开关 */
--energy: #ea7317; /* 电流路径 */
```

开关管配色全篇统一：**绿 = 常通、灰 = 常断、蓝 = PWM 开关**。

## 五、实现上的注意点

1. **设计基准 1600×900**，由 JS 按窗口等比缩放（`transform: scale()`）。改布局按这个尺寸想。
2. **SVG 箭头标记（`a1`–`a10`）定义在 `index.html` 顶部一次**，不要在各页 `<defs>` 里重复定义——重复会让颜色串掉（先出现的胜出）。
3. **SVG 文本里不能用 `<sub>`**，要写 `<tspan>` 或直接写 `Vgs1`、`iL`。
4. **`requestAnimationFrame` 回调的第一个参数是绝对时间戳，不是 delta**，必须自己算差值（见 `deck.js` 的 `last` 变量）。
5. **同一课件的多个页面里不要用重复的 `id`**，统一用 `data-*` 属性。
6. **`.row` 带 `grow` 会撑满整页，但卡片不会自动变高**。所以 CSS 里让 `.col` 内的卡片组竖直居中，否则内容会挤在顶部、下半页空白。
