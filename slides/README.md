# 功率控制与超级电容 · 培训幻灯片

给硬件组新人培训用的单页应用（SPA）式幻灯片。**双击 `index.html` 即可打开，不需要服务器、不需要联网。**

---

## 一、怎么用

### 打开
直接双击 `index.html`（推荐 Chrome / Edge）。

### 按键

| 操作 | 说明 |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> / <kbd>Space</kbd> / <kbd>PageUp</kbd> <kbd>PageDown</kbd> | 上一页 / 下一页 |
| <kbd>Home</kbd> / <kbd>End</kbd> | 第一页 / 最后一页 |
| **<kbd>G</kbd>** | **打开快速导航**（缩略图网格，点击跳转，可按部分筛选） |
| <kbd>F</kbd> | 全屏 |
| <kbd>Esc</kbd> | 关闭快速导航 |
| 鼠标滚轮 / 触屏左右滑 | 翻页 |

### 深链接
可以用 URL 直接跳到某一页，方便课间跳回：

- `index.html#12` —— 跳到第 12 页
- `index.html#buck-anim` —— 跳到 Buck 动画页（用 slide id）

## 四、怎么改内容

### 改幻灯片内容
所有内容在 `js/slides.js`，是一个数组：

```js
{
  id: 'buck-anim',        // 唯一 id，深链接与交互注册都用它
  part: 'Part II',        // 顶部的部分标签
  partKey: 'p2',          // p0 开场 / p1 功率控制 / p2 超级电容（决定配色）
  title: 'Buck 工作原理：看电流怎么走',
  sub: '12.1.1 · 四个管子里，右边两个是"固定"的',
  html: `...`             // 正文 HTML
}
```

新增一页 = 在数组里加一项。`cls: 'cover'` 是封面，`cls: 'divider'` 是分区页。

### 加交互
在 `js/deck.js` 末尾的 `INIT` 表里按 **slide id** 注册初始化函数：

```js
INIT['my-slide'] = el => {
  el.querySelector('.my-btn').onclick = () => { ... };
};
```

> ⚠️ **注册键必须等于 `slides.js` 里的 `id`**。这两处不一致时交互会静默失效——
> 本项目开发时就踩过这个坑（4 个交互页因为键名不匹配而完全没初始化）。

如果这一页有动画，返回 `{ pause, resume }` 对象即可：

```js
return { pause: () => cancelAnimationFrame(raf), resume: () => { raf = requestAnimationFrame(loop); } };
```

### 改配色 / 排版
统一在 `css/deck.css` 顶部的 `:root` 里：

```css
--p1: #2563eb;   /* Part I 主色 */
--p2: #0d9488;   /* Part II 主色 */
--on: #16a34a;   /* MOS 导通 */
--off: #94a3b8;  /* MOS 关断 */
--pwm: #3b82f6;  /* MOS 开关 */
--energy: #ea7317; /* 电流路径 */
```

开关管配色全篇统一：**绿 = 常通、灰 = 常断、蓝 = PWM 开关**——与教材图一致。

## 五、几个实现上的注意点

1. **设计基准 1600×900**，由 JS 按窗口等比缩放（`transform: scale()`）。
   改布局时按这个尺寸想。
2. **SVG 箭头标记（`a1`–`a10`）定义在 `index.html` 顶部一次**，
   不要在各页 `<defs>` 里重复定义——重复会让颜色串掉（先出现的胜出）。
3. **SVG 文本里不能用 `<sub>`**，要用 `tspan` 或直接写 `Vgs1`、`iL`。
4. **`requestAnimationFrame` 回调的第一个参数是绝对时间戳，不是 delta**，
   必须自己算差值（见 `deck.js` 里的 `last` 变量）。
5. 同一课件的多个页面里**不要用重复的 `id`**，统一用 `data-*` 属性，
   否则 `querySelector('#x')` 会拿到别的页面的元素。
