# 功率控制与超级电容 · 培训幻灯片

给硬件组新人培训用的单页应用（SPA）式幻灯片。**双击 `index.html` 即可打开，不需要服务器、不需要联网**（MathJax 已本地化）。

> **重心**：功率控制只讲逻辑（13 页），超级电容逐颗讲选型（37 页）。
> **版式**：深色社论风 —— 近黑底 + 荧光绿主色 + 巨大标题 + 等宽小标。
> **公式**：全部用 LaTeX 排版（MathJax 3，SVG 输出）。

## 二、视觉体系

改自一套社论风的排版语言，全部集中在 `css/deck.css` 顶部的 `:root`：

```css
--bg:     #111611;   /* 舞台底 */
--bg-deep:#080b09;   /* 窗口底 */
--panel:  #161d16;   /* 卡片 */
--fg:     #f5f5f3;
--muted:  #a8aea5;
--accent: #c5f76a;   /* Part I 主色：荧光绿 */
--cyan:   #69c8e0;   /* Part II 主色 */
--amber:  #f0b45e;
--rose:   #e8888a;
--line:   #2a322a;
--ease:   cubic-bezier(.2,.7,.2,1);
```

**排版层级**

| 元素 | 规格 |
|---|---|
| `.kicker` | 14.5px 等宽、字距 2.4px、荧光绿，后面拖一条细分割线 |
| `.slide-title` | 48px / 700 / 字距 −1.4px |
| 正文 | 16px / 行高 1.7 / `--muted` |
| `.formula` | 深色块 + 3px 左色条，内部是 MathJax 渲染的 LaTeX |
| `.var` | 等宽 + 主色，用于中文行文里的行内变量 |

**结构**：`#stage`（1600×900）内含 `.masthead`（顶）/ `.deck`（页面栈）/ `.stage-footer`（进度条 + 页码）。页面标题上方是 kicker，标注页码与小节号。

**开关管配色**全篇统一：**绿 = 常通、灰 = 常断、青 = PWM 开关、荧光绿虚线 = 电流路径**。

## 三、数学公式

用 **MathJax 3（tex-svg）**，已下载到本地 `js/mathjax-tex-svg.js`（2 MB，SVG 输出自带字形，不需要额外的字体文件，所以能离线用）。

**写法**：块级公式用 `$$ ... $$`

```js
<div class="formula p2">$$ \Delta I_L = \frac{U_2\,D\,(1-D)}{L\,f_{\mathrm{sw}}} $$</div>
```

行内公式用 `\( ... \)`（配置里已开）。

**按页懒排版**：`deck.js` 里的 `typesetSlide()` 在首次进入某页时才对那一页调 `MathJax.typesetPromise()`，避免一次排版 54 页导致首屏卡顿。

### ⚠️ 一个必须知道的坑

`\[ ... \]` 定界符**不能**直接写在 JS 模板字符串里 —— JS 会把 `\[` 当成转义序列、把反斜杠吃掉，于是 `\[` 变成 `[`，MathJax 认不出来，页面上就原样显示 LaTeX 源码。

所以本项目统一用 `$$ ... $$`：`$` 不参与转义，写在模板字符串里零风险。

（如果非要用 `\[`，必须写成 `\\[`。）

## 六、怎么改内容

内容拆成两个数据文件，加载时合并成一个数组：

```html
<script src="js/slides-p1.js"></script>   <!-- 开场 + Part I -->
<script src="js/slides-p2.js"></script>   <!-- Part II + 结尾 -->
```

每个文件都以 `window.SLIDES = (window.SLIDES || []).concat([...])` 开头，**顺序即加载顺序**。

单页格式：

```js
{
  id: 'sel-mos',          // 唯一 id，深链接与交互注册都用它
  part: 'Part II',
  partKey: 'p2',          // p0 开场 / p1 功率控制 / p2 超级电容
  title: '半桥 MOS：IRFH7440 与一张损耗账',
  sub: '12.5.4 · 选型就是算损耗',
  html: `...`
}
```

新增一页 = 在数组里加一项。`cls: 'cover'` 是封面，`cls: 'divider'` 是分区页。

### 加交互

在 `js/deck.js` 末尾的 `INIT` 表里按 **slide id** 注册：

```js
INIT['my-slide'] = el => { el.querySelector('.my-btn').onclick = () => { ... }; };
```

> ⚠️ **注册键必须等于 `slides-p*.js` 里的 `id`**。两处不一致时交互会静默失效，
> 页面上只留下初始的 `0.00` 之类占位值——本项目开发时就踩过这个坑。

有动画的页返回 `{ pause, resume }`。

## 七、实现上的注意点

1. **设计基准 1600×900**，由 JS 按窗口等比缩放 `#stage` 的 `transform: scale(var(--s))`。改布局按这个尺寸想。
2. **SVG 箭头标记（`a1`–`a10`）定义在 `index.html` 顶部一次**，不要在各页 `<defs>` 里重复定义——重复会让颜色串掉（先出现的胜出）。
3. **SVG 文本里不能用 `<sub>`**，要么写 `<tspan baseline-shift="sub">`，要么直接写 `Vgs1`。
4. **`requestAnimationFrame` 回调的第一个参数是绝对时间戳，不是 delta**，必须自己算差值（见 `deck.js` 的 `last` 变量）。
5. **同一课件的多个页面里不要用重复的 `id`**，统一用 `data-*` 属性。
6. **`.row` 带 `grow` 会撑满整页，但卡片不会自动变高**。所以 CSS 里让 `.col` 内的卡片组竖直居中。
7. **SVG 绘制顺序 = 图层顺序**。电流路径要画在"导线之后、开关管之前"，否则虚线会横穿 MOS 的标签。
8. **深色主题下不要在 HTML 里写死浅色**（`#fff`、`#f8fafc` 之类）。全篇颜色走 CSS 变量；SVG 里的 `fill`/`stroke` 也要跟着换成深色系。
